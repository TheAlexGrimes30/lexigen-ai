# LexigenAI

LexigenAI — интеллектуальная система анализа кредитных договоров на основе технологий Retrieval-Augmented Generation (RAG) и больших языковых моделей (LLM).

Система предназначена для анализа кредитных договоров, выявления юридических и финансовых рисков, формирования рекомендаций и предоставления консультационной информации по вопросам кредитного права на основе специализированной базы знаний.

## Основные возможности

- регистрация и авторизация пользователей;
- JWT-аутентификация;
- личный кабинет пользователя;
- управление подписками;
- создание и управление чатами;
- хранение истории сообщений;
- загрузка документов в форматах DOCX и PDF;
- автоматический анализ кредитных договоров;
- выявление юридических и финансовых рисков;
- поиск релевантной информации в базе знаний;
- генерация рекомендаций и аналитических выводов;
- экспорт результатов анализа;
- административная панель;
- логирование действий системы;
- автоматизированное тестирование с использованием Pytest.
