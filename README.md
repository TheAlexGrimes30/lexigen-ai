# LexigenAI

LexigenAI — интеллектуальная система анализа юридических документов на основе RAG (Retrieval-Augmented Generation) и LLM.

Проект предназначен для анализа кредитных договоров, выявления юридических рисков, слабых условий и формирования рекомендаций на основе базы знаний ГК РФ и внутренних юридических материалов.

---

# Цели проекта

## Основные цели

- Автоматизация анализа кредитных договоров
- Выявление юридических рисков и спорных условий
- Использование RAG для поиска релевантных норм права
- Интеграция LLM для генерации юридических выводов
- Поддержка загрузки документов через Web-интерфейс
- Масштабируемая архитектура по SOLID и MVC

## Подписки

Поддерживаются тарифы:

| Подписка | Стоимость |
|---|---|
| Basic | 1000 ₽ |
| Pro | 5000 ₽ |
| Enterprise | 20000 ₽ |

### Ограничения

- Пользователь без подписки:
  - может выполнить анализ документа только 1 раз

- Пользователь с подпиской:
  - может анализировать документы без ограничений

- Администратор:
  - может анализировать документы без ограничений даже без подписки
